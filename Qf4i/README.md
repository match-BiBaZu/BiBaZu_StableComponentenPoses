# Qf4i: grouped observed poses

10,000 completed drops; 9,835 settled. 29 assessed source poses; 16 groups meet the 1% cutoff.

Grouping uses 0.5 mm equivalent lift and a 60° maximum diameter. All members receive the same disturbance protocol.

## Main-parameter rerun, 2026-10-18

New **10,000** independent drop trials using the GUI defaults of simulator main `82f8bd43c70a`. The grouping extension runs on the feature branch; the physics, roughness, belt, release, geometry and parallel modules exactly match that main revision.

Chute: 45°/0°, 1,300 mm observation length; belt 100 mm/s without speed variation; drop height 100 mm without release spread; density 1.15 g/cm³; belt/wall friction 0.4/0.2. Weight impulses have Δv = 49.05 mm/s and a mean interval of 0.2 s, active only during the first second. The belt stops over 0.2 s, followed by 2 s of stationary observation. Seed 42; 24 independent workers. The 0.5 mm disturbance level is additionally assessed for grouping.

Stopped-belt observations: **10,000**; statuses: `{"settled": 10000}`. Group frequencies use the transport endpoint, as in the simulator; stopped-belt outcomes are separately recorded.
